# Troubleshooting

This guide helps you diagnose and resolve common issues with App Store for Intune.

- [Viewing logs](viewing-logs.md): Application Insights queries, the App Service log stream, packaging job status, and background service logs.
- [Common issues](common-issues.md): the 403 admin error, WinGet publishing errors, install-status problems, an empty assignment-filter dropdown, and migration issues.
- [Azure CLI and resources](azure-cli-and-resources.md): handy CLI commands and links to related guides.

## Getting help

If you can't resolve an issue:

1. **Gather information:**
   - Error message from Application Insights (full text)
   - Job ID or Request ID if applicable
   - Steps to reproduce the issue
   - Timestamp when the error occurred

2. **Ask Pax:** Select the chat icon in the bottom-right corner and describe the issue. Pax can often point you to the right guide or a known fix.

3. **Contact support:** If Pax doesn't resolve it, reach us through the [contact page](https://powerstacks.com/contact-us/) and include the information you gathered, along with your Application Insights query results and any screenshots.
