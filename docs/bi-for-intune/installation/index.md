# Installation overview

This section walks you through installing BI for Intune and connecting it to your tenant.

## What you'll do

1. Install BI for Intune from the Microsoft Marketplace.
2. Request a 30-day trial license.
3. Create the Microsoft Entra app registration.
4. Configure the BI for Intune semantic model with your tenant details.
5. (Optional) Customize data sync, enable Maps, and configure Cloud PC.

Plan for 30-60 minutes for the core install.

## Prerequisites

- A Power BI Pro license, Power BI Premium Per User license, or a Power BI tenant licensed for Power BI Premium. Microsoft offers a free Power BI Pro trial license via self-service sign-up.
- Global Admin and Subscription Admin rights for the user performing the setup.

## About Advanced Configuration

After the core install, the [Advanced Configuration](../advanced-configuration.md) section covers two optional add-ons:

- **Windows Update for Business Reports** — populates the WUfB Quality Updates, WUfB Feature Updates, WUfB Driver Updates, WUfB Delivery Optimization, and WUfB Windows Readiness dashboards.
- **Custom Inventory** — populates the Firewall Status, App Inventory, Driver Inventory, Microsoft 365, Monitor, Disk, Battery, and Warranty dashboards.

If you skip Advanced Configuration entirely, BI for Intune still works — but the dashboards above will be blank. That's expected, not a defect.
