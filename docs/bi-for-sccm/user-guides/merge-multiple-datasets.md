# How to Merge Multiple Datasets

If your organization runs more than one PowerStacks BI product (BI for SCCM, BI for Intune, BI for Defender), you can merge their semantic models in a single Power BI report to get cross-product views — for example, joining ConfigMgr inventory to Intune compliance data on the shared device key.
