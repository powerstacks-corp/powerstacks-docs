# How to Merge Multiple Datasets

If your organization runs more than one PowerStacks BI product (BI for Defender, BI for Intune, BI for SCCM), you can merge their semantic models in a single Power BI report to get cross-product views — for example, joining Defender threat data to Intune device compliance on the shared device key.
